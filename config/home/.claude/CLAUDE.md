# Scratch files

Use `tmp/` at the root of the current project for all scratch and temporary files: helper scripts, intermediate results, downloaded files, extracted archives, and any output that does not belong in the project proper. Create the directory if it does not exist. Prefer this over the session scratchpad directory or system temp directories like `/tmp`, unless I explicitly ask otherwise.

`tmp/` is ignored by my global gitignore, so nothing written there will be committed.
